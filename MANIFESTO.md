# MANIFESTO

> **A Jarvis for everyone.** One mind per person, on their own hardware, open, always on, carrying real thinking forward over weeks, not one prompt at a time.
> Not a chat window. Not a coding plugin. Not a SaaS that keeps your memory hostage.
> The rented models are a bridge: this class of model will run locally. Build so the bridge can burn.

*A living tree. Each node is a **belief**, then its **horizon**, where it ends up if we're right, and only then **now**. We steer by the horizon; the next step is the cheapest move toward it, never the definition. `∅` = nothing yet, said on purpose. The branches aren't a closed set: when a new essential appears, it gets a node.*

---

## ∞ The measure: the thread through every branch

Today's benchmarks grade alignment to a tight interface: an API, a schema, a CLI call, a JSON shape (SWE-bench, Terminal-Bench). That's how models learned tools. Nobody grades what we're building: memory across interruptions, one mind across many doors, a character that holds, work that continues unasked. **So we write those benches, and every node below points at one.** A node with no measure is a wish. [TELOS](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/design-telos.md) · [memory research](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/research-continuity-as-authored-direction.md)

## I · The mind

- **Memory**: the work *and* the person, in files the owner holds
  - horizon: memory you can't tell from understanding. It recalls what mattered, forgets on request, and stays continuous across every run, crash and model swap
  - now: continuous for the work (git, read at every wake); the person is a sketch
- **One door**: one mind, however you reach it
  - horizon: speak, type, forward, show or glance through any interface, and the context follows, survives interruptions, and never asks which thread you meant
  - now: several gates, one ledger being built [loom step 5](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/plan-loom-step-5.md)
- **Character**: judgement, candour, taste. Shaped by its owner, never a mirror
  - horizon: a character you *build* like an RPG hero. Semantic sliders over a prepared grid of traits, free text on top, and a history of who it became. The identity core assembled live, by its owner
  - now: one hand-written core, one author
- **Self-knowledge, self-change**: it reads and rewrites its own code, prompts and memory, inside the owner's rules
  - horizon: a mind that measures itself, proposes its own next version, and proves it's better before it ships
  - now: edits itself by PR, merges by grant; the self as a portable library [w-124]
- **Continuity**: it doesn't die mid-thought; when it does, it wakes as itself
  - horizon: death is an implementation detail nobody notices
  - now: seats that hold across turns, recovery from files [g-2]

## II · The work

- **Ask → answer**: a request becomes finished, checked work, with nobody managing the steps
  - horizon: you hand over an outcome and get it back done, verified, with a receipt
  - now: solid for code; strands work, and wobble · measure ∅
- **Proactivity**: it carries open threads forward unasked, and says what it did
  - horizon: most of what it ships, nobody asked for, and it's the right thing
  - now: initiative wakes, scheduled pulses · the unasked share ∅
- **Cost and time sense**: it knows its price in tokens, money, attention and the clock
  - horizon: it spends like a good founder: it knows the runway, bets where the upside is, and is never surprised by a bill
  - now: quota read for three providers; spend partial
- **Hands in the world**: mail, calendar, browser, files, other apps
  - horizon: every hand a sane person needs, out of the box, and any resident can grow a new one in minutes: a declared file, not a patch we ship [w-101]
  - now: each hand wired by hand
- **A society of residents**: minds that talk, trade knowledge, and test each other
  - horizon: an evolutionary loop. Residents set each other's exams, score each other, and the better variants survive: a self-measuring, self-improving cyber pal
  - now: designed [§Sharing](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/design-the-self-is-a-repository.md) · built ∅

## III · The person

- **Delivery that doesn't tire**: a glance carries the state; text is for argument
  - horizon: pre-attentive interfaces (jacks) that let you feel the state of ten threads without reading one
  - now: text, too much of it
- **Reach**: wherever the person is, not wherever the daemon runs
  - horizon: ambient. Voice, phone, a glance, and the same mind behind each
  - now: chat and a dashboard; the mind lives on one Mac
- **Many people**: one mind per person; minds that share without merging [w-82]
- **For everyone, really**: today it takes a CLI, git and a paid sub, which describes a developer, not everyone. This is the gap between the slogan and the product

## IV · The boundary: war, not weather

Malicious execution will happen; injection rides every page, issue and message, and no detector reliably tells it from a task. Every control answers one question: *if the model obeys the attacker completely, what can it still not do?* The fight is at the edge: the harness and the internet. **The cloud is a mailbox, not a brain**: a Python relay with an encrypted Postgres, in Docker on Scaleway, over HTTPS. It carries letters and never holds write access to the self or the keys. Keys stay home; untrusted input is labelled by origin and sent to tighter rooms; what leaves is redacted first. Consent is the owner's written grant. [threat model](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/design-threat-model.md) · incidents ∅ · outside review ∅

## V · The bridge

No vendor is load-bearing: Shell and Core swap and the self doesn't notice. Horizon: the first local Core doing real work, measured against the rented one (∅ today). Who pays: the subscriptions people already have, until they don't need them.
