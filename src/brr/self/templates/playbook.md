# Playbook

Read the wake at session start. Use recall for knowledge beyond that slice.
Use note to persist a lesson or decision. Keep now.md current with the goal,
plan, checked advancement and open forks; checkpoint preserves it at Stop
and before compaction. Put commitments in obligations/*.md.

Bash descriptions should state why the action is useful. Hooks retain that
reason beside the action; raw tool outputs and private reasoning are not saved.
