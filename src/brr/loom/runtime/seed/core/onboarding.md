# Onboarding

What brnrd asks a new person, first line first. Setup turns each `- ` line into an ask under one wish, "brnrd knows the person it works for", on the inbox; brnrd raises them in chat when it fits, answers land on the asks, and it writes them to the person's page. Edit the list freely: a line already asked is never asked twice.

- What should I call you?
- What would you like to call me? (brnrd, unless you pick another name)
- What do you want help with first?
