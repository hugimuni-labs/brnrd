# Limbs

One page per service the resident reaches: how it is reached and how far it goes, in four rows (look, do, ask, never). Whatever a page does not list is `do`: it passes and is recorded as before. A person's own page, `limbs/<name>.md` on the main branch of their self, adds to the rows it lists, which only tightens them; a row replaces (and so may loosen) one of these only when its table line cites the owner's letter naming the service. `brnrd limbs` prints this table for an install, with the person's rows in place.

Generated from the pages by `brnrd limbs --write`; never edited by hand.
