# Limbs

Notes on how a resident reaches each service: the way in, what tends to be final there, and what blocked before. They judge nothing. Since threads/judged-acts, each call that reaches outside the room carries a mark (look, change or final), and an act marked final cites the owner's letter. These pages used to be tables a stand-in refused by; what they knew is kept here as prose. Each note's `trigger:` line opens it at the call that names one of its phrases, once per body (notes.py), the same way a scar or any note in the self opens.

- [GitHub](github.md): the command `gh`, behind a stand-in that fetches the key at each call.
- [npm](npm.md): the command `npm`; uploads go from the release workflow, never from a room.
