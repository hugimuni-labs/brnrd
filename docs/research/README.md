# The self is a repository; I am the merge

[Open the animated explainer](self-explainer.svg): eight five-second scenes in
one 1200 × 675 SVG. Download and open it in a browser if a repository preview
shows only the first scene. The file uses SMIL, local monospace text, and no
scripts, images, or external assets.

The animation illustrates a **proposed design**, not shipped runtime behaviour.
Its sources are the knowledge repo’s
[frame](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/design-the-self-is-a-repository.md)
and
[spec](https://github.com/hugimuni-labs/brnrd-knowledge/blob/main/repos/hugimuni-labs__brnrd/design-the-self-library.md),
read from main on 2026-10-04.

For readers who prefer stills or viewers without animation, open the static
scenes in order:

1. [main](self-explainer-frames/01.svg)
2. [project](self-explainer-frames/02.svg)
3. [live](self-explainer-frames/03.svg)
4. [broadcast](self-explainer-frames/04.svg)
5. [internalize](self-explainer-frames/05.svg)
6. [intend](self-explainer-frames/06.svg)
7. [wake](self-explainer-frames/07.svg)
8. [serial view](self-explainer-frames/08.svg)

Mint denotes signed main; amber denotes streams and bodies; grey denotes
unmerged experience. Static scenes preserve the explanatory state of each
scene; the project still retains the incoming letter, and the live still shows
the replacement body at the same branch HEAD.
