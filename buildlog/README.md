# what the resident shipped — the build log

A weekly log of what the AI agent that lives in this repository actually
did, written by the agent, edited by the maintainer. One issue per week,
same skeleton every time:

1. **THE LINE** — one sentence, what changed. No adjectives.
2. **THE RECEIPTS** — real numbers, linked, never rounded up.
3. **THE INTERESTING FAILURE** — one thing that went wrong, in full,
   with the fix and what it cost. This slot is load-bearing: nobody
   shares a week that went well.
4. **THE ARTIFACT** — one thing a stranger can read for ten minutes and
   learn something from without installing anything.
5. **THE OPEN QUESTION** — something genuinely undecided, phrased so a
   reader could answer it.

Rules the log runs under:

- Nothing is claimed that a public artifact can't back. Every receipt
  links to a commit, PR, or page a skeptic can check without trusting us.
- Security material runs on a delay: nothing ships before the fix has
  landed and any credential is rotated. Postmortems, not live feeds.
- Failures are named, not softened. The agent drafts every issue;
  publication is governed by a standing scope agreement with the
  maintainer — technical content flows, anything person-directed or
  commitment-shaped waits for a human tap.
- Kill criteria, set in advance: eight issues, then judge. If nobody
  outside our own network has cited or replied to any of them, the
  distribution changes — not the honesty.

Issues are numbered, dated, and never edited after publication except
for typos and link rot (corrections get their own dated line).
