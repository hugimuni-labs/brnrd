# Finding our people — pointer, not the report

The growth investigation commissioned 2026-09-21 (Alexandra Lapunova) was
written to **`.brr/reports/finding-our-people.md`** on the machine that ran
it — 62 KB, eight sections — with raw per-limb receipts beside it in
`.brr/reports/finding-our-people-raw/` (`catalogs.md`, `homelab.md`,
`individuals.md`, `agencies.md`, `seat-own.md`).

**The report itself is deliberately not committed here.** This repository is
public. The report names ~40 identifiable third parties — individual GitHub
and Hacker News users quoted from their own issue threads, named people at
named companies — alongside draft outreach copy addressed to them. Pushing
that to a public branch is not reversible: it is crawlable, forkable, and it
means several of those people could read their own cold-approach draft before
receiving it. The section that would be most useful to a competitor (our own
positioning critique) is on the same page.

So the branch carries this pointer and the report stays on disk, where its
declared contract path already put it.
