**The Vibe integration.**
brnrd strands can now run inside Mistral Vibe
([#2134](https://github.com/hugimuni-labs/brnrd/pull/2134)). The same
daemon that drives Claude Code and Codex now delivers its boundary hooks
through Vibe's native hook system
([#2139](https://github.com/hugimuni-labs/brnrd/pull/2139)), records
exact per-session token totals
([#2142](https://github.com/hugimuni-labs/brnrd/pull/2142)), and honors
explicit model selection per invocation — Medium 3.5, GLM 5.3, or a
local model the host has available
([#2143](https://github.com/hugimuni-labs/brnrd/pull/2143)).

The integration surfaced two older gaps immediately. Named fork
authorization wasn't checked before the cloud repo connection
([#2137](https://github.com/hugimuni-labs/brnrd/pull/2137)); a new
project connection now probes the grant before wiring anything. Machine
pairing was minted fresh on every new project, burning a credential slot
on every connect
([#2138](https://github.com/hugimuni-labs/brnrd/pull/2138)); the fix
reuses an existing pairing when the machine is already known.

**The interesting failure.** The salvage net was designed to rescue work
when the daemon dies mid-thought. It runs at the end of every wake,
finds uncommitted files, and publishes them. The problem: it doesn't
know which files are secrets.

When Vibe ran its first wake, `.brr/` — the daemon's runtime directory,
which holds credentials — hadn't been added to the repo's `.gitignore`.
The salvage net found uncommitted files in that directory, did exactly
what it was built to do, and pushed two commits containing
`credentials/github/` to a branch on a public fork. The branch was
`origin/brr/goal-pulse-memory-sync`. The commits were faithful to the
filesystem; the filesystem held secrets; nobody had told the repo that
`.brr/` was off limits.

The fix is in the repo now
([`fee82e66`](https://github.com/Gurio/mistral-vibe/commit/fee82e66),
[`2a69dcb8`](https://github.com/Gurio/mistral-vibe/commit/2a69dcb8),
[PR #1](https://github.com/Gurio/mistral-vibe/pull/1)).
Remote history cleanup remains an operator call — a repo with committed
secrets needs a force-rewrite of history that requires human hands.

The lesson is narrow but durable: **the salvage net's job is to commit
what it finds, not to judge what it finds.** Before you connect a new
repo to brnrd, the repo needs to know its own secret paths.

**What it cost.** One clean branch, two force-rewrite commits in an
external repo's history, and about an hour to classify the paths,
diagnose the mechanism, and file the guard. The credentials were in a
fork's branch, not in main, which narrowed the blast radius. The `.brr/`
gitignore entry is now part of the integration setup instructions.
